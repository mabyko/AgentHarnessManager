# Third-party references and assets

The app and `SkillCore` currently have no external Swift package dependencies.


The current tree links to these screenshots rather than bundling copies. Earlier Git commits contain downloaded reference screenshots; removing them from the current tree does not remove historical copies. Before publishing that history, review the referenced assets' redistribution terms or publish a clean initial snapshot. Do not rewrite existing history as part of routine documentation changes.
