# Agent Plugin Manager

[English](README.md)

에이전트 스킬을 한곳에서 살펴보고, 작업별로 사용할 스킬 구성을 저장하는 macOS 네이티브 앱입니다. SwiftUI로 만들며 Codex와 Claude Code부터 지원합니다.

**현재는 초기 개발 단계입니다.** 로컬 `SKILL.md` 조회와 작업 구성 저장을 지원합니다. 플러그인 설치·업데이트와 MCP·훅·지침 관리는 앞으로 구현할 예정입니다. 앱 화면은 현재 한국어로 제공됩니다.

## 현재 지원하는 기능

- 기본 경로인 `~/.agents/skills`, `~/.claude/skills`와 직접 등록한 폴더에서 스킬 조회
- 사이드바에서 출처 저장소별 설치 항목 수와 출처 미확인 항목 확인. 이름·출처·경로 검색과 출처·에이전트·설치 위치·심볼릭 링크 필터 조합
- 에이전트와 설치 위치 필터 연동: 에이전트를 고르면 해당 경로만 표시하고, 특정 경로를 고르면 해당 에이전트도 선택. 에이전트를 바꾸면 맞지 않는 경로 선택을 해제. “모든 설치 위치”는 선택한 에이전트를 유지하고, “모든 에이전트”는 경로 선택도 해제. 출처·검색 결과가 없어도 등록한 경로는 선택 가능. 설치 위치 조회는 상단 필터로 모으고 경로 관리는 설정에서 제공
- 지원하는 전역 설치 기록으로 출처 자동 분류. 상세 화면에서 출처를 직접 연결·수정하거나 수동 연결 해제
- `SKILL.md` 원문 보기와 폴더 누락·접근 실패·불완전한 탐색 결과 안내
- 설정에서 기본 경로와 추가 경로를 함께 관리: 기본 경로는 고정이며, 추가 경로는 파일을 건드리지 않고 수정·등록 삭제 가능
- 작업 구성 생성·편집·삭제, 다른 구성의 스킬 선택 가져오기: 가져온 뒤 원래 구성을 바꿔도 저장한 구성은 유지
- 목록에서 사라진 스킬 참조 보존, 재실행 시 구성과 설정 복원
- 시스템 설정·라이트·다크 화면 모드

구성을 저장해도 스킬을 켜거나 끄거나 이동·삭제하지 않습니다. 파일을 발견했다고 에이전트가 실제로 읽은 것은 아닙니다. 다른 에이전트도 이름과 폴더를 등록해 `SKILL.md`를 조회할 수 있지만, 실행 호환성을 확인한 것은 아닙니다.

## 빌드와 실행

macOS 26 이상, Swift 6.2 이상을 포함한 Xcode 26 이상이 필요합니다. 전체 Xcode 설치를 활성 개발자 경로로 선택해야 합니다. 외부 Swift 패키지 의존성은 없습니다. 디자인 검사에만 Node.js 22 이상이 필요합니다.

저장소에 포함된 프로젝트를 열고 `AgentPluginManager` scheme을 선택해 실행합니다.

```sh
open AgentPluginManager.xcodeproj
```

저장소 루트에서 로컬 Release 앱을 빌드하고 실행하려면:

```sh
xcodebuild -project AgentPluginManager.xcodeproj \
  -scheme AgentPluginManager -configuration Release \
  -derivedDataPath build build
open "build/Build/Products/Release/Agent Plugin Manager.app"
```

기본 빌드는 ad-hoc 서명을 사용하므로 Apple 팀 설정이 필요하지 않습니다. Debug 빌드는 별도의 `Agent Plugin Manager Dev.app`과 설정 저장 영역을 사용합니다. 위 명령은 로컬 빌드용이며 Developer ID 서명과 공증 배포는 아직 검증하지 않았습니다.

생성된 Xcode 프로젝트를 저장소에 포함합니다. [project.yml](project.yml)을 변경해 프로젝트를 다시 생성할 때만 XcodeGen이 필요합니다.

```sh
xcodegen generate --spec project.yml
```

개인 서명 설정은 Git에서 제외하는 `Config/Local.xcconfig`에 작성합니다. 설정 방법과 검사는 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.

## 사용 방법

1. 설정(`⌘,`)에서 기본 스킬 폴더를 확인하거나, `SKILL.md`가 있는 폴더 또는 스킬을 모아 둔 폴더를 추가합니다.
2. 사이드바에서 출처를 고르고 에이전트·설치 위치로 목록을 좁힌 뒤, 항목을 열어 원문을 읽거나 Finder에서 확인합니다. 출처를 모르는 항목은 상세 화면의 “출처 연결…”로 연결합니다. 외부에서 파일을 바꾼 뒤에는 `⌘R`로 새로고침합니다.
3. 작업 구성을 만들고 필요한 스킬을 선택합니다. “다른 구성에서 가져오기”로 기존 선택을 재사용할 수 있습니다. 원래 구성에 현재 목록에서 사라진 스킬이 하나라도 있으면 가져오기를 막습니다.

## 로컬 데이터와 파일 접근

작업 구성·수동 출처 연결·추가 경로·화면 설정은 로컬 `UserDefaults`에 저장합니다. 현재 앱에는 계정·사용 정보 수집·네트워크 요청이 없으며, 스킬 스크립트를 실행하지 않습니다.

등록한 경로 안에서만 탐색합니다. 원문은 2 MiB 이하의 일반 UTF-8 파일만 읽고, 등록 경로 밖을 가리키는 링크는 차단합니다. 경로별 탐색 깊이는 8, 후보 수는 10,000개로 제한하며 불완전한 결과를 표시합니다. 이 수치는 앱의 제한이며 에이전트 명세가 아닙니다.

출처 자동 분류는 `~/.agents/.skill-lock.json`에 있는 버전 3 [Vercel Skills 설치 기록](https://github.com/vercel-labs/skills/blob/main/src/skill-lock.ts)을 읽습니다. 지원하는 GitHub/Git 기록을 `~/.agents/skills`의 해당 실제 폴더와 그 폴더를 가리키는 등록된 항목에만 연결합니다. 다른 위치의 동명 복사본은 출처 미확인으로 남깁니다. 이 메타데이터도 링크·특수 파일을 거부하고 2 MiB 이하만 읽습니다. `XDG_STATE_HOME`의 별도 기록, 프로젝트 기록, 플러그인 기록은 아직 지원하지 않습니다.

“설치 기록”은 설치 당시 기록, “직접 연결”은 사용자가 앱에서 지정한 출처입니다. 현재 파일과 원격 저장소의 일치 여부는 확인하지 않습니다. 개수는 원격 저장소의 스킬 수가 아니라 복사본과 링크를 각각 센 설치 항목 수입니다. 수동 연결은 발견한 설치 항목의 식별자에 저장하므로 폴더를 교체하면 자동 승계하지 않습니다. 수동 연결을 해제하면 설치 기록이 있는 항목은 그 출처로 돌아갑니다. 출처 선택·편집은 작업 구성이나 스킬 파일을 바꾸지 않습니다.

이름 변경 전의 설정을 유지하기 위해 기존 Bundle ID인 `forked.agentskillmanager.local`과 `.dev`를 보존합니다. [Config/Base.xcconfig](Config/Base.xcconfig)에 정의되어 있습니다.

## 앞으로의 계획

- 검증한 에이전트별 발견 규칙, 출처 기록 형식과 플러그인 소속 지원 확대
- 사용자 파일 쓰기를 연결하기 전에 변경 미리보기·충돌 검사·복구를 갖춘 스킬 변경 기능 구현
- 검증한 에이전트 공식 경로로 플러그인 설치·업데이트 지원, 이후 지원 가능한 MCP 서버·훅·지침으로 확장
- 접근성·배포 검수

플러그인은 배포 패키지, 저장소는 출처, 작업 구성은 사용자의 선택입니다. 단독 스킬은 그대로 다룹니다. 디자인 시안에는 미래 기능이 포함되어 있으며 현재 앱의 지원 범위를 뜻하지 않습니다.
