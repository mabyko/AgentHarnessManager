# macOS 디자인 시스템

제품명은 2026-10-19 **Agent Harness Manager**로 변경했습니다. 후속 화면에서는 플러그인·스킬·MCP·훅·지침을 원래 종류로 표시하고 패키지 포함 항목에는 소속을 보여줍니다. ‘플러그인’을 모든 항목의 새 분류로 사용하지 않습니다. 현재 구현과 확장 방향은 [README](../README.md#roadmap)를 따릅니다.

## 에이전트 아이콘

라이브러리의 에이전트 필터 메뉴, 전역 지침의 에이전트 메뉴, 연동 설정과 스킬 경로 선택 메뉴는 같은 `AgentIcon`을 사용합니다. 이름을 함께 표시하고 아이콘은 접근성 읽기에서 제외합니다. 일반 크기는 18 pt, 경로 제목은 16 pt이며 원본 비율을 유지합니다. 사용자 정의 에이전트는 시스템 터미널 아이콘을 사용합니다. 그룹·설정 카테고리 등 일반 기능 아이콘은 SF Symbols를 유지합니다.

공식 배포 이미지를 앱의 에셋 카탈로그에 포함해 네트워크와 에이전트 설치 여부에 관계없이 표시합니다. 단색 Pi는 기본 글자색을 따르고 나머지는 공식 색상과 밝은·어두운 배경용 변형을 사용합니다. Codex는 공식 확장 프로그램의 배경 포함 아이콘을 그대로 표시합니다. 이미지 출처와 상표 안내는 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md#agent-identity-icons)에 기록합니다.

## 설정 카테고리

설정 제목은 스크롤하는 Form 바깥에 고정하고 상단 스크롤 흐림 효과와 불필요한 사이드바 접기 도구를 제거합니다. 기본 창 크기는 900 × 680 pt이며 본문은 스크롤합니다. 에이전트 이름과 상태는 아이콘 오른쪽에서 같은 줄 시작점을 사용합니다.

설정 카테고리와 사이드바의 사용자 정의 버튼은 키보드 포커스를 받습니다. 카테고리의 접근성 그룹 이름은 하위 버튼 이름을 덮어쓰지 않습니다. 연결 설치·제거에는 에이전트 이름을, Finder 버튼에는 대상 경로를 포함합니다. 에이전트 정보는 이름과 상태를 함께 제공하고 장식 아이콘은 읽지 않습니다. 네이티브 접근성 검사는 별도 합성 창에서 수행하며 VoiceOver 음성 출력이나 시스템 전체 키보드 탐색 설정을 바꾸지 않습니다.

2026-10-21부터 작업 사이드바 행·설정 카테고리는 같은 `SidebarButtonStyle`을 사용합니다. 선택은 중립색 표면, hover와 눌림은 각각 낮은 농도의 명암 변화로 표현하며 위치나 크기를 흔들지 않습니다. 시스템의 큰 바깥 포커스 링 대신 `keyboardActivation`이 2 pt 안쪽 강조 테두리를 그립니다. 클릭은 `Button`, Space·Return은 한 번의 키 입력 처리 경로로 실행하며 비활성 상태에서는 실행하지 않습니다. 기본 동작 버튼은 macOS의 bordered/borderedProminent 표현을 유지합니다.

전역 지침에 진입해도 앱 사이드바를 바꾸거나 별도 돌아가기 링크를 만들지 않습니다. 가운데 열 상단에서 에이전트를 선택하고 기존 우선순위 순서로 파일 후보를 표시합니다. 기존 파일·없는 후보·공유 링크·초안·읽기 제한을 문구와 SF Symbol로 구분합니다. 없는 파일은 초안 작성 안내로 시작하고, 생성은 내용 입력·검토·명시적 적용을 거칩니다. 생성 기록과 현재 내용이 일치하는 새 파일에만 만들기 되돌리기를 제공하며 기존 파일 삭제 UI는 제공하지 않습니다. 세부 결정과 참고 자료는 [워크벤치 UX 개선안](design/workbench-ux.md)을 참고하세요.

설정은 macOS 방식의 왼쪽 카테고리와 오른쪽 상세 화면으로 나눕니다. 일반·에이전트 연동·스킬 경로를 구분합니다. 에이전트 연결은 Codex·Claude Code·Grok Build·Antigravity·OpenCode·Pi·Devin CLI·Cursor를 제공합니다. 각 행에 등록 상태를 표시하고 별도 확인 버튼을 제공합니다. 등록과 실제 연결은 구분합니다. 스킬 경로는 에이전트 선택 메뉴로 좁혀 기본 위치와 공유 호환 위치를 함께 표시하고 Antigravity 앱·IDE·CLI 경로를 구분합니다. 모델 계정 로그인이나 인증 정보 관리는 제공하지 않습니다.

일반의 스킬 설치에서 앱 직접 설치(기본)·skills CLI를 선택하고 실행 파일 감지 상태·경로·재확인·직접 선택을 제공합니다. CLI가 없으면 해당 선택을 비활성화하며 이미 선택한 CLI가 사라져도 다른 방식으로 자동 전환하지 않습니다. 설치 시트는 현재 방식을 표시하고 CLI에서는 임의 경로 대신 에이전트 하나를 선택합니다. 최종 검토는 실제 명령과 충돌 검사 경로, CLI가 파일·설치 기록을 관리한다는 점과 앱 자동 되돌리기 미지원을 안내합니다. 실행 중 시트 닫기·앱 종료를 막고 실패 후에는 자동 재실행하지 않습니다. 제거 방식은 앱의 복구 가능한 보관으로 유지합니다.

합성 경로·격리된 설정으로 확인한 네이티브 화면: [밝은 화면](design/native-agent-settings-light.png), [어두운 화면](design/native-agent-settings-dark.png). 스킬 경로 화면: [밝은 화면](design/native-skill-paths-light.png), [어두운 화면](design/native-skill-paths-dark.png).

에이전트 요청은 활동 이력의 요청 화면에서 조회합니다. 가운데 목록은 요청 제목·시각·관찰한 상태·이동 수를, 상세는 제안된 대상과 재검토·목록 제거를 제공합니다. 요청 제목은 에이전트가 보낸 데이터로 취급하고 적용 권한을 뜻하지 않습니다. 검토 후 기존 변경 검토 창에서 출발·도착을 다시 확인하고 적용합니다. [밝은 요청 화면](design/native-agent-request-light.png)·[어두운 요청 화면](design/native-agent-request-dark.png)은 합성 자료를 사용합니다.

## 2026-10-21 작업 중심 화면

화면은 사이드바·목록·상세의 3열로 구성하고 데이터 모델은 스킬·설치 위치·그룹을 분리합니다. 색상·서체·아이콘은 기존 스타일을 유지합니다. 기존의 작업 구성 중심 첫 화면·넓은 단일 목록·요청 시 상세 창은 현재 구현을 설명하는 기록이며 개편의 제약이 아닙니다.

- 왼쪽은 스킬 라이브러리·전역 지침·활동 이력 세 작업으로 고정합니다. 요약 타일, 개별 에이전트·그룹 필터와 새 그룹 행동은 사이드바에서 제거합니다. 설정은 도구 막대와 앱 메뉴에서 엽니다.
- 스킬 라이브러리 안에서 스킬·그룹·검사 결과를 전환합니다. 스킬의 보기 메뉴와 필터 버튼만 목록 위에 두고, 에이전트·그룹·설치 위치·출처·링크 조건은 하나의 팝오버에서 함께 적용합니다. 적용 조건 요약·결과 수·초기화를 목록 위에 표시하고 조건을 펼쳐도 목록 높이를 바꾸지 않습니다. 설치 버튼을 목록 제목 옆의 주요 행동으로 둡니다. 설치 시트에서는 GitHub·로컬 폴더 입력을 구분하고, GitHub는 주소 불러오기·스킬 선택·설치 위치·최종 검토 순서로 진행합니다. 설치 제거는 상세의 명시적 버튼으로 제공하며 별도 드롭다운에 숨기지 않습니다.
- 활동 이력 안에서 요청·변경·검사 이력을 전환하며 보존된 작업 구성이 있을 때만 보관을 표시합니다. 같은 작업을 다시 누르면 하위 화면과 필터를 유지하고, 활동으로 돌아오면 마지막 활동 화면을 엽니다.
- 가운데에는 현재 탐색 대상의 목록을, 오른쪽에는 선택 대상의 상세를 유지하는 3열 구조를 사용합니다. 라이브러리 상세에는 상태와 설치 제거 행동, 검사 결과, 설치 위치, 그룹, SKILL.md 본문을 배치합니다. 설치 카드는 영향받는 에이전트·역할·상태를 우선 표시하고 경로·출처는 접습니다. SKILL.md 본문도 요청 시 펼칩니다. 설치 제거는 대상 경로와 복구용 보관을 검토하며 Return 기본 행동으로 실행하지 않습니다.
- 그룹 목록에는 그룹별 스위치와 멤버 수, 단일/다중 활성 선택을 위한 모드를 둡니다. 그룹 상세에서는 멤버별 상태를 확인합니다. 기존 작업 구성을 반드시 거치도록 새 흐름을 추가하지 않습니다.
- 검사 결과에서는 필터와 결과 목록, 근거·개선안·관련 스킬 상세를 나눕니다. 검사 이력에서는 실행 목록과 실행별 결과·실패·재시도 정보를 보여줍니다.
- 무채색 표면·제한된 파란 강조색·시스템 서체·현재 아이콘 표현과 `WorkbenchTheme`는 유지합니다.

2026-10-20 2차 개편은 검사 이력과 별도로 변경 이력을 제공합니다. 완료·복구 필요 상태, 시각과 파일 이동 수를 목록에 표시하고 상세에서 이동 경로·그룹 선택·복구 재시도·되돌리기 검토를 제공합니다. 되돌리기는 원래 기록을 지우지 않는 새 작업이며 적용 전에 역방향 계획을 확인합니다. 검토 창과 중단 복구 중에는 그룹·경로 편집을 막습니다.

3차 개편은 공유 원본을 먼저 표시하고 보호 사유를 안내하며 에이전트별 설치 링크를 따로 전환합니다. 전체·그룹 전환은 설치 링크만 대상으로 삼습니다. 검토 행에는 링크 자체의 출발·도착과 유지할 원본·링크 문자를 구별하고 보관 중인 상대 링크를 직접 열지 않도록 안내합니다. 다단계·깨진 링크는 전환하지 않습니다.

지원 기능이 구현되기 전에 작동하지 않는 행동을 추가하지 않습니다.

제품은 SwiftUI와 macOS 기본 컨트롤을 사용합니다. 파일 접근 보호·변경 재검증·복구·키보드 탐색·색에 의존하지 않는 상태 표현은 개편에서도 유지합니다. 아래의 이전 시안과 충돌하는 배치·작업 구성 우선 규칙은 이 절을 우선합니다.

## 이전 시안의 기록

2026-10-01 사용자가 [차분한 작업대](design/final-candidate.md)를 기준으로 네이티브 프로젝트 구성을 승인했습니다. 개편 전 앱은 작업 구성 중심·넓은 설치 목록·요청 시 상세 창을 사용했습니다. 시각 스타일은 유지하고 현재 앱은 위 기준의 라이브러리·그룹·로컬 검사·검사 이력 3열 화면을 구현했습니다. AI 검토·자동 그룹화는 아직 구현하지 않았습니다.

[차분한 작업대](design/final-candidate.md)와 [상호작용 시안](design/final-preview.html)을 만들었습니다. 작업 구성을 첫 화면에 두고 설치 상세는 요청할 때 엽니다. 이전 앱은 이 방향의 읽기 전용 화면을 구현했으며 제품에는 예시 데이터를 포함하지 않습니다. 현재 색상은 최종 시안의 `design-tokens`와 앱의 `WorkbenchTheme`를 따르며 아래 초기 시안 값과 구분합니다.

후보의 현재 색상 원칙은 무채색 바탕과 제한된 강조입니다. 밝은 모드는 흰색·회색, 어두운 모드는 차콜·회색을 사용합니다. 파란색은 선택·포커스·주요 행동, 녹색은 상태, 황색은 주의, 적색은 오류에 사용합니다. 선택 영역의 넓은 바탕은 중립색으로 두고 일반 아이콘은 보조색을 사용합니다. 상태색은 문구·아이콘을 함께 제공하며 작업 구성 선택을 성공으로 표현하지 않습니다. 이전 녹색 팔레트는 배경까지 녹색이 넓게 쓰인다는 사용자 피드백으로 교체했습니다. 강조색은 제품 브랜드로 확정하지 않았습니다.

기준 창은 1280 × 800 pt, 최소 창은 960 × 640 pt를 제안합니다. 네이티브 렌더링은 지원 OS에서 검수하고, [브라우저 화면 시안](design/preview.html)은 구성과 상호작용을 검토하는 자료로 사용합니다.

출처 저장소·수동 그룹·작업 구성은 각각 출처 분류·임의의 모음·파일 목표입니다. 후보의 설치 목록에는 출처 필터를, 항목 상세에는 출처 근거·내부 위치·설치 방식·버전 확인 여부를 표시합니다. 미확인·사용자 지정·기록으로 확인됨을 문구로 구별하며 출처에 일괄 켜기 스위치를 두지 않습니다. 다중 선택의 `선택한 설치 항목으로 그룹 만들기`는 파일을 바꾸지 않으며 실제 적용은 작업 구성의 변경 검토를 거칩니다. 상세 동작은 [출처 분류 시나리오](product-scenarios.md#시나리오-15-출처-저장소로-정리하고-작업-구성에-연결)를 따릅니다.

| 요약 타일·상태·근거 카드 | 작은 SwiftUI 뷰 | 색상, 여백, 선택과 상태 |

3단 구성을 채택할 경우 [Apple NavigationSplitView](https://developer.apple.com/documentation/swiftui/navigationsplitview)를 사용할 수 있고 설정 창은 [Settings](https://developer.apple.com/documentation/swiftui/settings)에 대응합니다. 표준 컨트롤의 모양을 웹 시안의 CSS 값으로 재정의하지 않습니다. OS 재료 표현은 지원 버전과 새 스타일을 정한 뒤 검수합니다.

## 전환 행동과 문구

파일 변경은 `보관하기`·`원래 위치로 복원`처럼 대상과 행동을 명시하고 미리보기 후 실행합니다. 새 디자인의 컨트롤 모양을 바꾸더라도 파일 상태가 이미 변경된 것처럼 표현하지 않습니다. 앱 전체 고정과 즐겨찾기는 스킬 파일 변경 없이 반영합니다. 고정 자체는 복원하지 않으며 `고정됨 · 현재 보관됨`을 함께 표시합니다. 고정 보호는 새 단일 변경·프로필·완료 기록 되돌리기의 보관을 차단하고 중단 자동 롤백에는 별도 물리적 검증을 적용합니다.

그룹 화면에는 켜짐 스위치를 두지 않습니다. 그룹에 든 항목의 파일 상태 요약과 `프로필에 사용` 행동을 표시합니다. 프로필 목록은 라디오 버튼으로 현재 대화의 활성 프로필을 단정하지 않고 실제 구성 일치 여부를 보여줍니다.

그룹·프로필 저장과 삭제는 파일을 옮기지 않습니다. 참조 중인 그룹은 프로필에서 연결을 해제한 뒤 삭제합니다. 첫 버전은 부분 적용과 관련 항목의 자동 확장을 제공하지 않습니다. 관계 확인 후 사용자가 목표를 편집하고 새 미리보기를 확인합니다.

첫 버전은 메인 창 하나와 설정 창을 사용합니다. 실행·복구 중에는 발견 루트·보관 위치·고정·그룹·프로필·관리 범위 편집을 막고 이유를 표시합니다. 조회·즐겨찾기·외형 변경은 계속 제공합니다. 보관 위치는 원자료를 담은 위치로 설명하고 자동 정리나 캐시 삭제 행동을 제공하지 않습니다. 등록 해제는 검사 비활성화이며 기록과 원래 위치 정보를 보존합니다.

| 상황 | 문구 예시 | 제공할 행동 |
| --- | --- | --- |
| 단일 보관 미리보기 | Claude Code의 링크 1개를 보관합니다. 공유 원본은 유지됩니다. | 취소, 1개 항목 보관 |

| 계획 변경 | 미리보기 이후 항목이 변경되었습니다. 변경 내용을 다시 확인해 주세요. | 다시 검사 |

성공 메시지는 자동으로 사라져도 기록에서 다시 볼 수 있습니다. 차단·복구 오류는 사용자가 처리하기 전까지 유지합니다. 실패 이유에는 해결 행동을 연결합니다.

## 키보드와 접근성

`⌘F` 검색, `⌘R` 다시 검사, `⌘,` 설정을 제공합니다. 목록 이동은 기본 방향키·선택 동작을 사용합니다. Return은 기본 선택 행동입니다. 준비 중 Escape는 미리보기 취소이며 실행 중에는 화면만 닫지 않고 중단 요청으로 처리합니다. 중단 요청 후 되돌리는 중·중단 완료·복구 필요를 구별합니다. 메인 창 닫기는 실행 취소가 아니며 창을 다시 열면 같은 작업을 확인할 수 있습니다. 앱 종료는 안전한 중단과 기록 경로를 거칩니다. 쓰기를 단축키 한 번으로 즉시 실행하지 않습니다.

모든 아이콘 행동에는 접근성 이름과 도움말을 제공합니다. 같은 이름 항목의 접근성 이름에는 전체 설치 위치를 포함합니다. 선택과 상태를 VoiceOver에 전달하고, 검사 완료·적용 완료는 포커스를 빼앗지 않고 알려줍니다. 변경 확인 영역은 제목과 대상·영향부터 읽고, 닫힌 뒤 실행을 시작한 컨트롤이나 남아 있는 적절한 위치로 포커스를 되돌립니다. 드래그로 그룹 편집하는 기능에는 메뉴나 버튼 대안을 제공합니다.

텍스트 크기 변경, 고대비, 투명도 감소, 동작 감소를 검수합니다. 커스텀 애니메이션은 선택 강조와 짧은 상태 전환에 한정하고, 파일 작업의 성공 여부를 애니메이션 종료에 의존하지 않습니다. 웹 시안은 `prefers-reduced-motion`을 따릅니다.

## 빈 화면과 실패 화면

최종 후보의 검색은 현재 화면의 대상을 찾는다. 명시적인 화면 이동에서는 검색어를 비우고, 재검사·외부 관찰에서는 검색어를 유지한다. 설치 목록의 결과 수는 상태·출처·검색을 모두 반영한 표시 수와 출처 범위 전체 수를 구별한다. 좁은 창에서도 동일 이름 항목을 식별할 에이전트·설치 경로를 화면에 남긴다. 작업 구성의 상세 확인은 현재 화면과 구성을 유지하고, 현재와 목표가 다른 행에만 전후 문구·강조를 표시한다. 에이전트 조회 필터가 적용되지 않는 화면은 필터를 비활성화하고 이유를 설명한다.

| 상태 | 보여줄 내용 |
| --- | --- |
| 설치 항목 없음 | 스킬 위치를 추가하면 여기서 확인할 수 있습니다. 위치 추가 |
| 검색 결과 없음 | 현재 범위에서 일치하는 항목이 없습니다. 검색어 지우기 |
| 일부 위치 접근 실패 | 성공한 결과 유지, 실패 위치와 다시 검사 표시 |
| 프로젝트 없음 | 프로젝트 폴더를 등록해 범위를 좁힐 수 있습니다. 프로젝트 추가 |
| 검사 중 | 기존 결과 유지, 진행 상태·취소 표시 |
| 상세 항목 누락 | 마지막 알려진 위치와 누락 상태, 다시 검사 |
| 복구 필요 | 새 스킬 파일 변경과 안전 설정 편집 차단, 조회·즐겨찾기·외형은 허용 |
| 수동 해결 필요 | 두 위치 확인·외부 처리·재관찰·명시적 결과 확인과 기록 후 종료 |

## 화면 시안의 검토 범위

시안에서 검색, 항목 선택, Codex·Claude 조회 필터, 그룹·프로필·검사·기록 탐색, 밝은/어두운 모드, 프로필 미리보기와 적용, 충돌 분류를 확인할 수 있습니다. 파일 변경은 예시 데이터 안에서만 시뮬레이션합니다.

실제 네이티브 타이틀바, 시스템 메뉴, VoiceOver, OS 재료 표현과 파일 권한은 브라우저 시안으로 검증할 수 없습니다. SwiftUI 구현 후 해당 OS에서 화면 크기·테마·접근성 설정을 맞춰 검수합니다.

본 명세와 시안 계산의 정합성을 확인한 뒤 읽기 전용 코어와 임시 폴더의 쓰기 코어를 구현합니다. 실제 사용자 파일에 대한 쓰기 안전성은 아직 검증하지 않았으며 코어의 실제 파일 테스트 통과 뒤 연결합니다. 새로운 레이아웃·색상·탐색 디자인은 이 동작 계약을 바탕으로 별도로 진행합니다.
